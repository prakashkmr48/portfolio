# Knowledge Base

Knowledge base content helps users and support teams solve repeat questions quickly. I write KB articles, FAQs, SOPs, and internal documentation that turn known processes and issues into searchable self-service guidance.

## Knowledge Base Content

<div class="content-grid" markdown>

- **FAQs**  
  Direct answers to recurring user, support, product, or operational questions.

- **Support articles**  
  Problem-solution content for common product, platform, or workflow issues.

- **SOPs**  
  Standard operating procedures for repeatable internal or operational tasks.

- **Internal documentation**  
  Process references, team workflows, review steps, and documentation support content.

</div>

## KB Article Pattern

| Section | Purpose |
| --- | --- |
| Question or issue | Search-friendly title |
| Applies to | Product, environment, workflow, or audience |
| Answer | Short direct answer |
| Details | Explanation, steps, or context |
| Validation | How to confirm the answer or process worked |
| Related articles | Links to supporting documentation |
