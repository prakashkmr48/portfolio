# Developer Guides

Developer documentation helps technical readers move from concept to implementation. I write developer guides that define prerequisites, explain architecture context, show task flows, and connect API details with practical usage.

## Developer Documentation Types

<div class="content-grid" markdown>

- **Integration guides**  
  Step-by-step flows for connecting systems, services, APIs, or product features.

- **Implementation notes**  
  Technical context, decision points, dependencies, and configuration considerations.

- **Developer onboarding**  
  Setup instructions, local environment guidance, tools, and first successful workflow.

- **Reference support**  
  API links, configuration values, code-adjacent examples, and troubleshooting paths.

</div>

## Writing Pattern

1. Define the developer goal.
2. List prerequisites and assumptions.
3. Explain the system or feature context.
4. Provide implementation steps.
5. Add examples, expected results, and validation checks.
6. Link to API reference, configuration, and troubleshooting pages.
