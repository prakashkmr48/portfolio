# User Guides

User guides translate product behavior into clear, task-based instructions. I write user documentation for readers who need to complete work accurately without decoding internal product or engineering language.

## User Guide Scope

<div class="content-grid" markdown>

- **Task-based procedures**  
  Clear steps, expected results, notes, warnings, and validation checks.

- **Admin guidance**  
  Setup, permissions, configuration behavior, operational tasks, and user management.

- **Product workflows**  
  End-to-end usage flows organized around reader goals.

- **Support-ready help**  
  Linked troubleshooting, FAQs, and related knowledge base topics.

</div>

## Page Pattern

| Section | Purpose |
| --- | --- |
| Before you begin | Prerequisites, access, required setup, and assumptions |
| Procedure | Numbered steps focused on reader action |
| Expected result | What the user should see or confirm |
| Notes and warnings | Important constraints, risks, or product behavior |
| Troubleshooting | Common issues and recovery paths |
| Related topics | Configuration, release notes, KB articles, or admin guides |
