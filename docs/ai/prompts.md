# Prompt Engineering

Prompt engineering documentation helps users create better instructions for AI systems. I document prompt patterns in a way that is practical, testable, and easy to reuse.

## Documentation Focus

<div class="content-grid" markdown>

- **Prompt patterns**  
  Role, task, context, constraints, examples, and output format.

- **Usage examples**  
  Before-and-after prompts, structured instructions, and repeatable workflows.

- **Testing**  
  Evaluation criteria, output checks, iteration, and quality review.

- **Responsible usage**  
  Limits, review expectations, sensitive content handling, and human validation.

</div>

## Prompt Pattern

```text
Role: Define what the AI should act as.
Task: State the outcome clearly.
Context: Provide source information and constraints.
Output: Specify format, tone, and structure.
Review: Check accuracy, completeness, and suitability.
```
