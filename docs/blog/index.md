## Publishing Standards

- Use descriptive titles and summaries.
- Write for a clear audience and search intent.
- Include examples, tables, or checklists where useful.
- Link related portfolio and documentation pages.
- Avoid confidential employer information.
- Avoid invented metrics or claims.
